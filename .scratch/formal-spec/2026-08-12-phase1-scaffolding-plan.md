# Formal Spec Phase 1 — Scaffolding Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Promote the six failure-mode specs out of `.scratch/` into a first-class `specs/`
directory, evolve `scripts/failure-modes.py` into the spec linter `scripts/spec-lint.py`
(`just lint-spec`) that understands the new `TR-`/`LV-`/`CO-` id spaces, install the Quint
toolchain and agent skills, and publish the specs to the website — with no spec *content*
migration (that is phase 2+).

**Architecture:** Three independent tracks, sequenced so the tree is green after every task.
(1) **Relocation + lint**: rename the script/recipe first (pure rename, green), then move the six
specs and repoint the linter in one atomic task, then add the new checks one at a time behind
fixture tests. (2) **Toolchain**: Quint CLI via mise's npm backend plus a no-op-until-models
`just quint-check`, and the `quint-lang`/`quint-modeling` agent skills installed project-scoped.
(3) **Publishing**: a `website/scripts/spec-gen.py` generator (same shape as the existing
`compat-gen.py`/`matrix-gen.py`) that injects Starlight frontmatter, rewrites repo-relative
links, and writes `website/src/content/docs/specifications/`, wired into the docs recipes, the
sidebar, and a generated CI job.

**Tech Stack:** Python 3.11+ PEP-723 scripts run with `uv run` (stdlib only, no test framework —
plain assert scripts), `just` recipes, `lefthook` pre-commit, GitHub Actions generated by
`workflow_gen` (Python), Astro/Starlight website built with `bun`, Quint CLI from npm via `mise`.

## Global Constraints

- **Session build mode is `local`.** Everything runs on this machine; never call a `tb-*` recipe.
- **Long-running commands** (`just lint`, `just docs-build`, any workspace compile) follow
  CLAUDE.md "Long-Running Commands": checkpoint-commit first, launch with the Bash tool's
  `run_in_background: true`, `taskpolicy -B -p <pid>` the spawned `rustc`/`cargo` processes, poll
  with short foreground tails. Never `nohup`/`&`.
- **Pre-production, no backwards compatibility**: `lint-failure-modes` → `lint-spec` is an
  outright rename. No alias recipe, no shim `failure-modes.py`, no deprecation note.
- **Edit generators, not generated files**: `.github/workflows/*.yml` are generated — edit
  `.github/workflows/workflow_gen/src/workflow_gen/workflows/*.py` then run `just workflow-gen`.
  `website/src/content/docs/specifications/*.md` are generated — edit
  `website/scripts/spec-gen.py` then run `just spec-gen`.
- **`just` recipes over raw tools**: `just test <crate> <pattern>`, `just lint`, `just docs-build`
  — never bare `cargo`/`bun`/`npx`. Use `bun`, never npm/npx, for anything JS.
- **Python scripts run via `uv`**: repo convention is a `#!/usr/bin/env -S uv run --script`
  shebang with a PEP-723 header and stdlib-only dependencies; invoke as `uv run --offline
  <script>` or via the executable bit. Tests are plain assert scripts with a `main()` that runs
  every `test_*` global — no pytest.
- **The six specs are LOCKED.** Their content moves unchanged: every `FM-<AREA>-NNN` id, every
  `Forced by` test name, every table row is byte-identical apart from (a) intra-document relative
  links repaired by the move and (b) stale `frogdb-server/src/...` code paths corrected to
  `frogdb-server/crates/server/src/...`. Spec-first discipline and the mutation gates are
  untouched by this plan.
- **Green at every task boundary**: `just lint-spec`, `just test-spec-lint`, `just lint-gates` and
  `just scratch-check` must pass before each commit; `just lint` (workspace clippy, long) is run
  in the final verification task.
- **Commits**: conventional style (`feat:`, `refactor:`, `docs:`, `chore:`, `ci:`), no
  `Co-Authored-By` lines, no `--no-verify`. Use `git commit` with explicit pathspecs — this repo's
  lefthook stages fixed files, and other agents may share the tree.
- **macOS `sed`**: in-place edits need the empty-argument form `sed -i '' -E ...`. Prefer `sed`
  sweeps over per-file editing for mechanical renames (many instances).
- **Reference-rewrite rule for `.scratch/`**: *paths* are rewritten everywhere (a path that no
  longer exists is a dead pointer), but *command names* inside `.scratch/**/issues/done/**` are
  left alone — "`just lint-failure-modes` OK (278 modes)" is a true historical record of a command
  that existed when the issue closed. `.scratch/formal-spec/**` (the design doc and this plan) is
  excluded from every sweep for the same reason.

Four scope calls worth stating so a reviewer does not read them as oversights:

- **TR rows are not required to name a forcing test** (design §2 asks for it). A TR row is a
  legal-transition definition, and what forces it is the area's whole test suite; the rule needs
  the first real TR rows to be designed against. Deferred to the cluster phase — LV rows, whose
  forcing tests are concrete turmoil quiesce/eventually tests, get the rule now (Task 5).
- **`just lint-spec` is not added to CI or to the lefthook compile-free subset.** Design §2 says
  it "runs where the current lint runs … the full family in `just lint` and CI", but today
  `lint-failure-modes` runs *only* via `just lint` — which lefthook skips under `CLAUDECODE=1`,
  and which CI does not invoke (the `lint` job runs `cargo clippy` directly). Wiring it into CI
  is a real gap, but it is a change in what CI enforces on 279 existing rows, not scaffolding;
  it belongs in its own change. This plan preserves today's coverage exactly.
- **No CI or nightly wiring for Quint** (design §3 cadence). It lands with the first model.
- **The `architecture/*.md` pages are left as they are.** Design §6 rewrites each one as a
  narrative overview *as its area's spec lands*; phase 1 lands no area content, so nothing there
  is superseded yet.

    FM rows keep their own type because they carry the seven required fields of
    a failure mode. A constructive row's schema is written area by area as the

def parse_spec(path: Path, errors: list[str]) -> tuple[list[FailureMode], list[SpecRow]]:
    """Parse one `specs/<area>.md` into its FM rows and its constructive rows."""
    area = path.stem.upper()
    modes: list[FailureMode] = []
    rows: list[SpecRow] = []
    current: FailureMode | SpecRow | None = None

    for lineno, raw in enumerate(path.read_text().splitlines(), start=1):
        stripped = raw.strip()

        heading = HEADING_RE.match(stripped)
        if heading:
            fm_id, fm_area, number, title = heading.groups()
            if fm_area != area:
                errors.append(
                    f"{path.relative_to(REPO)}:{lineno}: {fm_id} does not match the "
                    f"file's area prefix FM-{area}-"
                )
            if not title:
                errors.append(f"{path.relative_to(REPO)}:{lineno}: {fm_id} has no title")
            current = FailureMode(
                id=fm_id,
                area=fm_area,
                number=int(number),
                title=(title or "").strip(),
                spec=path,
                line=lineno,
            )
            modes.append(current)
            continue

        constructive = CONSTRUCTIVE_HEADING_RE.match(stripped)
        if constructive:
            row_id, kind, row_area, _number, title = constructive.groups()
            if row_area != area:
                errors.append(
                    f"{path.relative_to(REPO)}:{lineno}: {row_id} does not match the "
                    f"file's area prefix {kind}-{area}-"
                )
            if not title:
                errors.append(f"{path.relative_to(REPO)}:{lineno}: {row_id} has no title")
            current = SpecRow(
                id=row_id,
                kind=kind,
                area=row_area,
                title=(title or "").strip(),
                spec=path,
                line=lineno,
            )
            rows.append(current)
            continue

        composition = COMPOSITION_HEADING_RE.match(stripped)
        if composition:
            row_id, _number, title = composition.groups()
            if not title:
                errors.append(f"{path.relative_to(REPO)}:{lineno}: {row_id} has no title")
            current = SpecRow(
                id=row_id,
                kind="CO",
                area="",
                title=(title or "").strip(),
                spec=path,
                line=lineno,
            )
            rows.append(current)
            continue

        if current is None:
            continue
        row = ROW_RE.match(stripped)
        if not row:
            continue
        field_name, value = row.group(1), row.group(2)
        if field_name in ("Field", "---") or set(field_name) <= {"-", ":"}:
            continue
        current.fields[field_name] = value

    for mode in modes:
        for required in REQUIRED_FIELDS:
            if required not in mode.fields:
                errors.append(f"{mode.where()}: {mode.id} has no `{required}` row")
        mode.tests = parse_forced_by(mode, errors)

    return modes, rows

```python
def parse_specs(spec_dir: Path, errors: list[str]) -> tuple[list[FailureMode], list[SpecRow]]:
    specs = sorted(spec_dir.glob("*.md"))
    if not specs:
        errors.append(f"no spec files under {rel(spec_dir)}")
        return [], []

    modes: list[FailureMode] = []
    rows: list[SpecRow] = []
    for spec in specs:
        spec_modes, spec_rows = parse_spec(spec, errors)
        modes.extend(spec_modes)
        rows.extend(spec_rows)

    seen: dict[str, FailureMode | SpecRow] = {}
    for entry in [*modes, *rows]:
        if entry.id in seen:
            errors.append(
                f"{entry.where()}: {entry.id} redefined (first at {seen[entry.id].where()})"
            )
        seen[entry.id] = entry

    # Numbering is sequential per area; a gap usually means a section was
    # dropped without renumbering. Loud, but not a failure. FM only — the
    # constructive id spaces are still being written and will be gappy by
    # construction until an area's migration finishes.
    by_area: dict[str, list[int]] = {}
    for mode in modes:
        by_area.setdefault(mode.area, []).append(mode.number)
    for area, numbers in by_area.items():
        expected = set(range(1, max(numbers) + 1))
        gaps = sorted(expected - set(numbers))
        if gaps:
            missing = ", ".join(f"FM-{area}-{n:03d}" for n in gaps)
            print(f"warning: gap in {area} numbering: {missing}", file=sys.stderr)

    return modes, rows
```

```python
def check_spec_references(spec_dir: Path, defined: set[str], errors: list[str]) -> int:
    """Fail on a spec id a document cites and no row defines.

    The `INV-*` vocabulary check above does this for invariants against the
    Rust catalogs; this is the same discipline for the spec's own id spaces.
    Live for `FM-` from day one (279 rows cross-cite across areas), vacuous for
    `TR-`/`LV-`/`CO-` until the constructive sections land — which is when a
    citation is most likely to rot, so the check has to exist before them.

    Returns the citation count, for the summary line.
    """
    citations = 0
    for spec in sorted(spec_dir.glob("*.md")):
        for lineno, line in enumerate(spec.read_text().splitlines(), start=1):
            for ref in SPEC_REF_RE.findall(line):
                citations += 1
                if ref not in defined:
                    errors.append(
                        f"{rel(spec)}:{lineno}: cites `{ref}`, which no spec row defines"
                    )
    return citations
```

```python
def check_quint_citations(
    quint_dir: Path,
    defined: set[str],
    catalogs: dict[str, Catalog],
    errors: list[str],
) -> tuple[int, int]:
    """Every spec id a Quint model's header cites must resolve.

    A model states the rows it models in its leading `//` comment block (design
    §3). Only that block is scanned: the body is Quint, and `quint typecheck`
    owns it. An `INV-` citation may name any registered area's catalog, because
    a composition model spans areas by construction — the per-area rule the
    specs live under does not apply here.

    Returns (models, citations); both are zero until the first model lands.
    """
    models = 0
    citations = 0
    catalog_ids = {ref for catalog in catalogs.values() for ref in catalog.ids}
    for path in sorted(quint_dir.glob("*.qnt")):
        models += 1
        cited = 0
        for lineno, line in enumerate(path.read_text().splitlines(), start=1):
            if line.strip() and not line.lstrip().startswith("//"):
                break
            for ref in SPEC_REF_RE.findall(line):
                cited += 1
                if ref not in defined:
                    errors.append(
                        f"{rel(path)}:{lineno}: cites `{ref}`, which no spec row defines"
                    )
            for ref in INV_REF_RE.findall(line):
                cited += 1
                if ref not in catalog_ids:
                    errors.append(
                        f"{rel(path)}:{lineno}: cites `{ref}`, which no invariant "
                        "catalog defines"
                    )
        citations += cited
        if cited == 0:
            errors.append(
                f"{rel(path)}: header cites no spec ids — a model names the "
                "`TR-`/`INV-`/`LV-`/`CO-` rows it models in its leading comment block"
            )
    return models, citations
```

Create `website/scripts/spec-gen.py`:

```python
#!/usr/bin/env -S uv run --script
# /// script
# requires-python = ">=3.11"
# dependencies = []
# ///
"""Generate the website's Specifications section from `specs/*.md`.

`specs/<area>.md` is the single source of truth (see
`.scratch/formal-spec/2026-08-12-formal-state-spec-design.md` §6). Each spec is
copied into the Starlight content collection with frontmatter injected, its H1
consumed as the page title, and its repo-relative links rewritten:

  * a sibling spec link (`replication.md#fm-replication-001`) becomes a site
    route (`/specifications/replication/#fm-replication-001`);
  * every other repo-relative link becomes a GitHub blob URL, because the
    target — an issue under `.scratch/`, a Rust source file — is not published
    and would otherwise be a dead link in the built site.

Usage:
    uv run website/scripts/spec-gen.py            # generate
    uv run website/scripts/spec-gen.py --check    # verify (CI)
"""

from __future__ import annotations

import argparse
import posixpath
import re
import sys
from pathlib import Path

# ---------------------------------------------------------------------------
# Paths
# ---------------------------------------------------------------------------

SCRIPT_DIR = Path(__file__).resolve().parent
REPO_ROOT = SCRIPT_DIR.parent.parent
SPEC_DIR = REPO_ROOT / "specs"
OUT_DIR = REPO_ROOT / "website" / "src" / "content" / "docs" / "specifications"
GITHUB_BLOB = "https://github.com/frogdb/frogdb/blob/main/"
GENERATED = "<!-- DO NOT EDIT — auto-generated by: just spec-gen (source: {source}) -->"

# Sidebar order and the one-line blurb per area. A spec with no entry here is
# an error rather than a default: order and blurb are editorial choices the
# generator cannot infer, and a new area should be introduced deliberately.
AREAS: dict[str, tuple[int, str]] = {
    "cluster": (1, "Cluster topology, slot ownership, migration, and failover."),
    "replication": (2, "Replication sessions, full sync, offsets, and acknowledgement."),
    "persistence": (3, "WAL, checkpoints, recovery, and durability acknowledgement."),
    "txn": (4, "MULTI/EXEC transactions, WATCH, and script atomicity."),
    "vll": (5, "Very Lightweight Locking: acquisition, continuation, and drain."),
    "blocking": (6, "Blocking commands: waits, wakeups, and disconnect handling."),
}

# `](target)` or `](target "title")`
LINK_RE = re.compile(r"\]\(([^)\s]+)((?:\s+\"[^\"]*\")?)\)")

# ---------------------------------------------------------------------------
# Rendering
# ---------------------------------------------------------------------------


def rewrite_link(target: str) -> str:
    """A spec's link target, as the published page should carry it."""
    if target.startswith(("http://", "https://", "mailto:", "#")):
        return target
    path, sep, anchor = target.partition("#")
    fragment = f"#{anchor}" if sep else ""
    if not path:
        return target
    if path.endswith(".md") and "/" not in path and Path(path).stem in AREAS:
        return f"/specifications/{Path(path).stem}/{fragment}"
    # Anything else is repo-relative from `specs/` and is not published.
    return GITHUB_BLOB + posixpath.normpath(posixpath.join("specs", path)) + fragment


def render(spec: Path) -> str:
    order, blurb = AREAS[spec.stem]
    lines = spec.read_text().splitlines()
    if not lines or not lines[0].startswith("# "):
        sys.exit(f"spec-gen: {spec.name} does not start with an H1 title")
    title = lines[0].removeprefix("# ").strip().replace('"', "'")
    body = "\n".join(lines[1:]).lstrip("\n")
    body = LINK_RE.sub(lambda m: f"]({rewrite_link(m.group(1))}{m.group(2)})", body)
    front = "\n".join(
        [
            "---",
            f'title: "{title}"',
            f'description: "{blurb}"',
            "sidebar:",
            f"  order: {order}",
            "---",
            GENERATED.format(source=f"specs/{spec.name}"),
            "",
        ]
    )
    return f"{front}\n{body.rstrip()}\n"


def render_index(specs: list[Path]) -> str:
    rows = "\n".join(
        f"| [{spec.stem.capitalize()}](/specifications/{spec.stem}/) | {AREAS[spec.stem][1]} |"
        for spec in specs
    )
    return "\n".join(
        [
            "---",
            'title: "Specifications"',
            'description: "The authoritative, lint-enforced specification of FrogDB\'s '
            'state and behavior, one document per area."',
            "sidebar:",
            "  order: 0",
            "---",
            GENERATED.format(source="specs/"),
            "",
            "These documents are the authority for FrogDB's behavior: each row states a rule",
            "and names the tests that force it. They are generated from the repository's",
            "`specs/` directory, and a lint checks in both directions that every row names a",
            "test and every tagged test names a row — a rule nothing forces is a gap, not a",
            "claim.",
            "",
            "| Area | Scope |",
            "|---|---|",
            rows,
            "",
        ]
    )


# ---------------------------------------------------------------------------
# Entry point
# ---------------------------------------------------------------------------


def main() -> int:
    ap = argparse.ArgumentParser(description=__doc__)
    ap.add_argument(
        "--check",
        action="store_true",
        help="verify the generated pages are up to date instead of writing them",
    )
    args = ap.parse_args()

    specs = sorted(SPEC_DIR.glob("*.md"))
    if not specs:
        print(f"spec-gen: no specs under {SPEC_DIR}", file=sys.stderr)
        return 1
    unknown = [spec.stem for spec in specs if spec.stem not in AREAS]
    if unknown:
        print(
            f"spec-gen: no AREAS entry for {', '.join(sorted(unknown))} — give the new "
            "area a sidebar order and a one-line scope blurb in spec-gen.py",
            file=sys.stderr,
        )
        return 1

    pages = {f"{spec.stem}.md": render(spec) for spec in specs}
    pages["index.md"] = render_index(specs)
    existing = {path.name: path.read_text() for path in sorted(OUT_DIR.glob("*.md"))}

    if args.check:
        stale = sorted(set(existing) - set(pages))
        missing = sorted(set(pages) - set(existing))
        changed = sorted(name for name in pages if name in existing and existing[name] != pages[name])
        if stale or missing or changed:
            for name in missing:
                print(f"spec-gen: missing generated page {name}", file=sys.stderr)
            for name in changed:
                print(f"spec-gen: {name} is out of date", file=sys.stderr)
            for name in stale:
                print(f"spec-gen: {name} has no source spec", file=sys.stderr)
            print("spec-gen: run `just spec-gen`", file=sys.stderr)
            return 1
        print(f"spec-gen: {len(pages)} generated pages are up to date")
        return 0

    OUT_DIR.mkdir(parents=True, exist_ok=True)
    for name in sorted(set(existing) - set(pages)):
        (OUT_DIR / name).unlink()
    for name, text in pages.items():
        (OUT_DIR / name).write_text(text)
    print(f"spec-gen: wrote {len(pages)} pages to {OUT_DIR.relative_to(REPO_ROOT)}")
    return 0


if __name__ == "__main__":
    sys.exit(main())
```
